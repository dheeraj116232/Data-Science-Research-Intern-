# MongoDB-RAG-Render

This repository contains three project folders:

- `rag-chatbot`: Next.js RAG chatbot application
- `customer-segmentation`: notebook and dataset for customer segmentation analysis
- `banking-eda`: banking EDA notebook and datasets

## Notes

- The repository is structured as a single top-level Git repo.
- Local environment artifacts such as `.venv/`, `.env*`, `node_modules/`, and `.next/` are ignored.
- `rag-chatbot/.git-history-backup/` is excluded from tracking so the app can be committed as part of this repository.
