# Data Science Research Intern Portfolio

This repository showcases three projects across exploratory data analysis, customer analytics, and applied AI engineering. It combines notebook-driven research work with a deployable Retrieval-Augmented Generation application.

## Projects

### `rag-chatbot`

A Next.js chatbot that uses OpenAI, LangChain, and MongoDB Atlas Vector Search to answer questions from uploaded PDF documents.

- Stack: Next.js, TypeScript, LangChain, MongoDB Atlas, OpenAI
- Focus: document ingestion, vector search, retrieval-augmented generation
- Main files: `rag-chatbot/src/app`, `rag-chatbot/README.md`

### `customer-segmentation`

A customer analytics notebook that explores customer attributes and segmentation patterns using a structured CSV dataset.

- Stack: Python, Pandas, Jupyter Notebook
- Focus: customer profiling, segmentation analysis, descriptive analytics
- Main files: `customer-segmentation/customer_segmentation_analysis.ipynb`, `customer-segmentation/README.md`

### `banking-eda`

An exploratory data analysis project on banking marketing data, covering data inspection, pivot tables, and visualization.

- Stack: Python, Pandas, Matplotlib, Jupyter Notebook
- Focus: EDA workflow, feature exploration, campaign analysis
- Main files: `banking-eda/banking_customer_eda.ipynb`, `banking-eda/README.md`
