# Customer Segmentation

This project explores customer behavior through segmentation analysis using a Jupyter notebook and a structured CSV dataset.

## Files

- `customer_segmentation_analysis.ipynb`: main analysis notebook
- `customer_segmentation_data.csv`: source dataset used in the notebook

## Focus Areas

- customer profiling
- pattern discovery
- segmentation-oriented exploratory analysis
- notebook-based reporting

## Tools

- Python
- Pandas
- Jupyter Notebook

## Outcome

The notebook is intended to identify meaningful customer groups and support data-driven marketing or product decisions through descriptive analysis.
